Descrição do Projeto

Este projeto foi desenvolvido no contexto da disciplina de **Interface do Usuário** com o objetivo de aplicar, na prática, conceitos fundamentais de design centrado no usuário. A proposta consiste na criação e evolução de protótipos que representem a estrutura, o fluxo de navegação e a interação de uma aplicação.

Inicialmente, foi elaborado um **protótipo de baixa fidelidade**, composto por esboços simples que priorizam a organização das informações e a definição das principais funcionalidades. Essa etapa permitiu validar ideias rapidamente, com foco na arquitetura da interface e na experiência do usuário de forma geral.

Em seguida, foi desenvolvido um **protótipo de média fidelidade**, no qual os elementos visuais foram refinados, incluindo layout mais estruturado, componentes de interface e maior detalhamento das interações. Essa evolução possibilita uma compreensão mais clara do funcionamento da aplicação antes da implementação final.

O projeto busca demonstrar o processo iterativo de design, evidenciando a importância da prototipação como ferramenta para análise, validação e melhoria contínua da experiência do usuário.
